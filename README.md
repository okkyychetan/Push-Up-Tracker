# Push-Up-Tracker
A real-time Push-Up Tracker built with Python, OpenCV, and MediaPipe. It detects body landmarks, calculates elbow angles, and automatically counts push-ups. Includes live angle display, pose overlay, and animated progress bar using a webcam.

# How it Works
1.It captures webcam feed using OpenCV
2.Uses MediaPipe Pose to detect key landmarks
3.Calculate elbow angles to determine pushup motion
4. Count reps and display feedback in realtime
